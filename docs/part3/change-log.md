# Change log: Part 2 to Part 3

Changes to the AI agent since the Part 2 submission (commit `7db8733`, November 12, 2026), and why each was made. The Project Evaluation Platform is tracked separately.

| Date | Change | Why |
| --- | --- | --- |
| Nov 25 | Every citation the agent gives is shown in a citation check table: the citation, what the agent claimed, what the official source says, and the result (correct, partly correct, wrong, invented or not checked). | The Part 3 brief requires every legal citation to be checked against an official source, and AI tools invent sections that look real. |
| Nov 25 | `prompts/citations.json` became the single citation register. The agent cites listed provisions by register ID, and a lint (`npm run citations:lint`, run on every build) fails if a prompt names an ID that does not exist or writes a citation out in prose. | So each citation the agent gives can be looked up and checked, and the law is listed in one place instead of several prompt files. |
| Nov 25 | Download of the complete, unedited transcript, including the model used and the full system prompt. The raw model replies are kept so the transcript is exactly what the model returned. | Deliverable 2 requires the complete, unedited transcript. |
| Nov 25 | The conversation is saved in the browser and restored on reload. | A long evaluation was lost if the page was refreshed before the transcript was saved. |
| Nov 26 | The Part 3 proposal was added word for word as `docs/part3/project.md`. | The platform and the agent must be given the same project description. |
| Nov 26 | Every register entry was checked against Ontario e-Laws, the Justice Laws Website, the Supreme Court of Canada, PEO or the City of Toronto Municipal Code, with what the source says and the date checked. Entries found out of date were corrected (the Building Code now cites O. Reg. 163/24, and endangered species law the Species Conservation Act, 2025). | So no unchecked or invented citation is presented as correct. |
| Nov 26 | 24 provisions a subway station project engages were added and checked, including the accessibility standards for transit (notice and alternatives during service disruptions), the City of Toronto Act sections the TTC operates under, the confined spaces regulation, the Fire Code sections on ventilation shutdown testing, hot work on ducts and fire safety plans during construction, the environmental approval exemptions for ventilation equipment, municipal privacy law on collecting personal information (for the passenger-count sensors) and the Toronto noise by-law. The discipline guidance now says a TTC subway is under provincial, not federal, jurisdiction, and gives the treaty territory for the Keele Campus. | The Part 2 register was built for our Part 1 cases (offshore rig and rail) and did not cover work in an operating subway station. |
| Nov 27 | Download buttons export the citation check table for the current assessment as Markdown or CSV. | The report needs a citation check table for the actual agent run. |
| Nov 27 | Gemini became the primary model, with Groq as the backup, and slow providers are skipped before the hosting time limit. | Groq's free tier allows fewer tokens per minute than the system prompt, so requests to it failed. |
| Nov 28 | The five interview personas were added as `docs/part3/personas.md`, with a "Part 3: York Station ventilation" example that sends the proposal and personas together. The system prompt tells the agent to use personas as stakeholder evidence (mainly in Q3), not as facts or a reason to change a score, and the report has a new "Persona concerns" table showing whether each persona's needs and worries are addressed. | The brief requires the agent to be given the persona summaries, and the comparison asks what the personas raised that the tools did not. |

Final register: 107 checks across 58 instruments, all checked against official sources (87 correct, 20 partly correct).
